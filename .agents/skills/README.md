# .agents/skills

本目录存放全组复用的 AI 提示词与技能说明，避免每个人重复描述同一套口径。

## 内容

- [prompts.md](prompts.md)：五个角色各自的代码生成提示词，以及容器/CI、文档协作两类通用提示词。

## 使用方式

1. 从 `prompts.md` 复制对应角色的提示词。
2. 把返回的完整代码按 `docs/03_项目架构与接口.md` 的目录保存。
3. 本地自测（模块底部有 `__main__` 自测，或跑 `pytest backend/tests -q`）。
4. 报错时连同完整红色报错交回 AI，并附加固定约束：**不要修改函数名、入参与返回字段，只修复报错并输出完整代码。**

## 固定约束

- 坐标原点左上，x 右 y 下，20×20，合法坐标 0–19。
- 接口失败统一 409 + `{"ok": false, "msg": 原因}`。
- 三个 `sim/` 模块只依赖 Python 标准库。
