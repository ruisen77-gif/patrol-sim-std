# 02 小组分工

## 1. 小组信息

| 项 | 内容 |
|---|---|
| 小组名称 | 智能巡检仿真小组 |
| 目标版本 | 基础版 + 标准版 + 进阶版七项拓展 |
| 专项方向 | Web 全栈仿真（Flask + Canvas） |

## 2. 任务安排

| 任务 | 负责人 | 主要交付 | 验收方式 | 状态 |
|---|---|---|---|---|
| 全栈 | 成员A | `frontend/index.html`、`backend/app.py`、根 `README.md`、`docs/03` | 页面可操作，接口与文档一致 | 已完成 |
| 运维 | 成员B | `Dockerfile`、`docker-compose.yml`、`ci.yml`、三份 `AGENTS.md`、`docs/02`、`docs/04` | 一条命令起服务，CI 绿灯 | 已完成 |
| 算法 | 成员C | `backend/sim/path_planner.py` 及单元测试 | 绕障路径正确，不可达有说明 | 已完成 |
| 人工智能 | 成员D | `backend/sim/sensor_sim.py` 及单元测试 | 移动后感知结果随之变化 | 已完成 |
| 嵌入式仿真 | 成员E | `backend/sim/robot_sim.py` 及单元测试 | 手动可动、越界被拦、巡检可跑 | 已完成 |

## 3. 联调约定

| 项 | 约定 |
|---|---|
| 联调负责人 | 全栈（成员A） |
| 首次联调场景 | 手动控制链路：点方向键 → `/api/move` → 坐标变化 → 碰撞 / 越界有提示 |
| 前端准备 | 按 `docs/03` 接口表发送请求，不私自增加字段 |
| 后端准备 | 按 `docs/03` 接口表返回数据，失败统一 409 + `msg` |
| 坐标与字段口径 | 已写入 `docs/03_项目架构与接口.md`，改动须全员同意 |
| 联调顺序 | 手动控制 → 自动巡检 → 传感器告警 → 容器与 CI |

| 成员 | 角色 | 实际提交内容 | 自测记录 |
|---|---|---|---|
