# 运行与结业提交

## 本地运行

- 使用的操作系统和环境版本为 `windows11/macOS 27.2.1、Python 3.11`。
- 前后端启动顺序为 `先启动后端Flask服务，前端静态页面由后端直接提供，无需单独启动`。
- 页面入口为 `http://127.0.0.1:5050`，后端 API 地址为 `http://127.0.0.1:5050/api`。
- 启动后执行 `浏览器访问页面地址`，预期看到 `20×20仿真地图页面，可对机器人下发控制指令`。

依赖安装、配置、启动命令和单端验证步骤分别见[前端 README](../frontend/README.md)与[后端 README](../backend/README.md)。

## Docker 部署

1. 从 `仓库根目录` 执行命令，所需 Docker 环境为 `Docker Desktop 24+`。
2. 按 `项目现有Dockerfile、docker‑compose.yml` 准备配置，所需配置项与示例值为 `容器暴露5050端口`。
3. 使用 `docker compose build` 构建镜像，再执行 `docker compose up` 启动服务。
4. 打开 `浏览器访问 http://127.0.0.1:5000`，执行 `查看页面、下发机器人控制指令` 验证页面和 API，预期结果为 `仿真地图正常加载，后端接口正常响应，业务代码开发完成后生效`。
5. 使用 `docker compose down` 停止服务。
