# 04 运行与结业提交

## 1. 环境要求

- Python 3.9 及以上（容器内为 3.11）
- Docker 24 及以上（可选）

## 2. 本地运行

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r backend/requirements.txt

python backend/app.py
```

浏览器打开 <http://localhost:5050>。

端口默认 5050，可通过环境变量修改：

```bash
PORT=8000 python backend/app.py
```

> 模板示例端口为 5000，本项目统一使用 5050：macOS 的 AirPlay 接收器默认占用 5000，直接绑定会失败。需要对齐模板时用 `PORT=5000 python backend/app.py`（先关闭「隔空播放接收器」）。

## 3. Docker 部署（五步）

1. 构建镜像：

   ```bash
   docker compose build
   ```

2. 启动服务：

   ```bash
   docker compose up -d
   ```

3. 浏览器打开 <http://localhost:5050>，确认地图与机器人正常显示。

4. 验证一次手动控制：点方向键，坐标变化；撞向障碍或走出边界时弹出告警。

5. 停止并清理：

   ```bash
   docker compose down
   ```

一条命令完成 1–2 步：`docker compose up --build`。

### 构建失败的处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 拉取 `python:3.11-slim` 失败 | 无法访问 Docker Hub | 先从可用镜像源拉取并重命名：`docker pull <mirror>/library/python:3.11-slim && docker tag <mirror>/library/python:3.11-slim python:3.11-slim` |
| pip 安装超时 | PyPI 访问慢 | `docker compose build --build-arg PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple` |

## 4. 测试

```bash
pytest backend/tests -q
```

三个模块也可单独自测：

```bash
python backend/sim/robot_sim.py
python backend/sim/path_planner.py
python backend/sim/sensor_sim.py
```

## 5. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面显示「后端连接中断」 | Flask 未启动或端口不通 | 确认 `python backend/app.py` 仍在运行，检查 `PORT` |
| 巡检启动后状态不更新 | 路径下发阻塞了请求 | 确认 `follow` 在后台线程中推进 |
| 容器内 404 | 静态目录未复制 | 检查 Dockerfile 是否复制 `frontend/` |
| 容器内 ImportError | sim 包未复制 | 检查 Dockerfile 是否复制 `backend/` |
| 巡检点全部不可达 | 点位被障碍物包围 | 换一个空格重新设置 |

## 7. 展示安排

演示按下列顺序进行，每步一句话说明：

1. 打开页面，指出地图、障碍物、机器人朝向。
2. 方向键移动两格，撞墙一次，展示告警弹窗与坐标不变。
3. 点击地图设置 P1、P2、P3，展示标记与目标高亮。
4. 调速度滑块到 4x，启动巡检，展示路径、轨迹、进度与到达顺序。
5. 演示一次不可达点位（围死一格）触发失败提示。
6. 结束时说明容器一条命令启动与 CI 绿灯。
