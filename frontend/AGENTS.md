# Frontend Agent 协作文档
所属：智能巡检机器人二维仿真系统 patrol-sim-std
角色：前端可视化代理，负责人机交互、地图渲染、状态展示

## 1. 文件归属边界
本目录 `frontend/` 属于前端 Agent 维护范围。
- ✅ 归属：index.html、页面样式、地图渲染逻辑、交互逻辑、网络请求封装
- ❌ 不属于：仿真逻辑、机器人运动计算、持久化状态
- 改动规则：前端只修改视图、请求调用；不能私自修改后端接口语义。

## 2. 坐标与字段口径
和后端保持完全一致，不自行转换坐标系：
- `x`：水平，m，浮点数
- `y`：竖直，m，浮点数
- `theta`：航向角，弧度
- `status`：`idle` / `moving` / `arrived` / `blocked`

前端拿到后端数据直接映射渲染，坐标换算统一放在前端渲染层。

## 3. 接口格式约定
前端作为请求方，遵守后端 JSON 协议：
- 请求 Content-Type：`application/json`
- 解析后端 `code` 判断业务结果，`data` 取业务内容
- 接口异常：弹窗提示错误信息，不阻塞页面

> 前端为静态页面，所有业务HTTP请求统一访问后端服务地址 `http://127.0.0.1:5050`。

请求示例（下发导航目标）：
```json
{
  "x": 2.0,
  "y": 3.0,
  "theta": 0
}
```

## 4. 常用命令

方式 1：直接本地打开
双击 `index.html` 使用浏览器打开（file 协议，部分跨域接口会受限）。

方式 2：Python 简易静态服务（推荐，规避 file 协议跨域）

```bash
python -m http.server 8080
```

启动完成后浏览器访问：`http://127.0.0.1:8080`

方式 3：Docker 单独构建部署前端静态页面（基于 nginx）

提示：执行该命令需要 frontend 目录下存在 nginx 类型 Dockerfile，否则构建失败。

```bash
# 在 frontend 目录执行构建镜像
docker build -t patrol-static-frontend .
# 运行容器，示例映射本机8081端口
docker run -d -p 8081:80 patrol-static-frontend
```

## 5. 协作约束

- 前端是"视图层"：只展示、收集用户点击，运动规划交给后端
- 轮询/请求频率控制：状态轮询不要过于频繁，避免压垮后端
- 端口约定：前端是静态页面，本身不绑定固定端口；后端接口服务固定 `5050`
- 接口变更：发现字段对不上，先和后端对齐口径再调整页面
- Docker 部署：使用静态资源服务器托管 index.html，端口在 compose 中自行配置
- 更新部署前清理旧容器，避免页面缓存问题
