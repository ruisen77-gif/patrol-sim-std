# frontend/AGENTS.md

## 边界

- 只做渲染与请求：不实现寻路、不判断碰撞规则、不维护机器人状态。
- 状态一律来自后端：`/api/robot` 与 `/api/sensor`，每 1 秒轮询。
- 路径、轨迹、目标点由前端本地缓存 `plan` 并结合机器人坐标推导，不另造接口。

## 约定

- 画布 20×20，`PAD=20`、`CELL=28`，点击坐标换算必须与后端一致（左上角为原点，y 向下）。
- 请求失败时读 `msg` 弹窗，不吞掉后端给的原因。
- 告警弹窗可关闭；碰撞、越界、不可达三类文案不可混用。
- 不引入外部 CDN、不拆分构建，保持单文件。

## 联调检查

1. `python backend/app.py` 后打开 <http://localhost:5050>。
2. 点方向键：坐标卡变化；撞墙时弹窗且坐标不变。
3. 设置巡检点 → 启动巡检：路径出现、进度更新、完成后状态为「已完成」。
